\doxysection*{❓ What is clibs?}

{\bfseries{clibs}} is a collection of utility code (types, typedefs, macros, functions) used across C programs. ~\newline
 It is self-\/contained and domain-\/neutral, designed to be applicable in various contexts.

\DoxyHorRuler{0}


\doxysection*{🖥️ System Requirements}


\begin{DoxyItemize}
\item A C compiler that supports ANSI C
\item GNU Make (for testing only)
\end{DoxyItemize}

{\bfseries{clibs}} is written in ANSI C (C89). However, we have tested it with C89, C99, and C11. ~\newline
 You can use it with either classic or modern C codebases.

We have successfully compiled and run {\bfseries{clibs}} with\+:


\begin{DoxyItemize}
\item GCC
\item Clang
\item Visual C++
\item Intel C++ Compiler
\end{DoxyItemize}

We also test {\bfseries{clibs}} on the following Unix or Unix-\/like systems\+:


\begin{DoxyItemize}
\item Ubuntu 20.\+04 LTS
\item Rocky Linux 8.\+5
\item open\+SUSE Leap 15.\+3
\item Free\+BSD 13.\+0
\end{DoxyItemize}

It should also work on other Unix-\/like systems.

Additionally, we test {\bfseries{clibs}} on Windows using \href{https://www.appveyor.com/}{\texttt{App\+Veyor}}, ~\newline
 so it should be compatible with Windows as well.

\DoxyHorRuler{0}


\doxysection*{📦 How to Use}

The utilities in {\bfseries{clibs}} are self-\/contained, provided either as\+:


\begin{DoxyItemize}
\item single-\/header files, or
\item single-\/header + single-\/source file combos.
\end{DoxyItemize}

Just copy the components you need into your C project.

Files starting with {\ttfamily test\+\_\+\texorpdfstring{$\ast$}{*}.c} are for testing purposes and are {\bfseries{not required}} for using {\bfseries{clibs}}.
