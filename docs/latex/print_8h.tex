\doxysubsection{Detailed Description}
Thread-\/aware printing macros with redirect support. 

This module provides print macros (like printf, puts) that redirect output to thread-\/local FILE\texorpdfstring{$\ast$}{*} streams, with fallback to stdout/stderr. Intended for portable, lock-\/free console or file printing.
